# hello-claude

Demo repo for my first Claude Code PR.

## What is this?

A sandbox repository used to practice the full GitHub PR workflow with [Claude Code](https://claude.ai/code) — from writing a change to opening and merging a pull request.

## Getting started

```bash
git clone https://github.com/mjenca-cmd/hello-claude.git
cd hello-claude
```

## Contributing

1. Create a branch: `git checkout -b my-change`
2. Make your change and commit it
3. Push and open a PR: `gh pr create`
